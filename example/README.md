# awesome_bottom_sheet example

A small app that exercises every feature of the package: the four message
types, awaited results, custom styling, single-button sheets, custom icons and
content, auto dismiss, non-dismissible sheets, dark mode and the
`AwesomeBottomSheetThemeData` theme extension.

```sh
cd example
flutter run
```

The full source is in [lib/main.dart](lib/main.dart).
